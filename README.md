# نور الشام · منيو QR

منيو رقمي لمطعم وجبات سريعة (HTML / CSS / JS فقط، بدون باك إند).

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` · `style.css` · `script.js` | المنيو عند الزبون |
| `data.js` | الأصناف والأسعار وأرقام نظام المحاسبة (`code`) — مشترك بين الصفحتين |
| `order.html` · `order.css` · `order.js` | صفحة الكاشير التي تفتح عند مسح رمز الطلب |
| `logo.svg` | لوغو المطعم |

## كيف يعمل الطلب
1. الزبون يختار أصنافه ويضغط **إنشاء رمز الطلب**.
2. يظهر QR يحتوي الطلب كاملاً داخل الرابط.
3. الكاشير يمسحه بكاميرا موبايله فتفتح `order.html` بالطلب وأرقام الأصناف.
4. يُدخل الطلب على نظام المحاسبة كالمعتاد ويطبع الوصلين.

الأسعار لا تُرسل في الرابط، بل تُحسب دائماً من `data.js`.
